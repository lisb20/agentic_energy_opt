# Vendored OpenEvolve runtime

This directory contains the minimal runtime files needed from OpenEvolve
version 0.2.25. Examples, tests, documentation assets, repository history, and
development-only files are intentionally omitted from the supplementary
package.

Upstream project: <https://github.com/algorithmicsuperintelligence/openevolve>
